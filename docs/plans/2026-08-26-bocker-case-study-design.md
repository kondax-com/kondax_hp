# Bocker 実績ページ追加デザイン

## 目的

Yadora を残したまま、美容サロン向け予約・顧客管理プラットフォーム Bocker を独立した実績として追加する。正式 URL は `/[locale]/work/bocker` とし、実績一覧、グローバルナビゲーション、フッターから到達できるようにする。

## デザイン

KONDAX の白基調と Yadora 実績ページのエディトリアルな情報設計を踏襲する。Bocker では公式サイトの淡いブルー、濃紺、細いグリッドをアクセントにし、提供された公式サイトのスクリーンショットを主役にする。画像は浮遊感のあるフレームに収め、本文は課題、運用フロー、主要機能、プロダクト価値、公式サイト CTA の順で構成する。

## 実装範囲

- 日英対応の Bocker 専用ケーススタディ
- `/work` への Bocker 特集カード追加
- ナビゲーションとフッターへの導線追加
- canonical、言語別 URL、OG メタデータ
- `next/image` によるレスポンシブ画像配信

## 検証

- `npm run build` で型チェック、SSG、サイトマップ生成を確認する
- 日本語と英語の両ルートをブラウザで確認する
- モバイル幅とデスクトップ幅で画像、見出し、CTA の崩れがないことを確認する
