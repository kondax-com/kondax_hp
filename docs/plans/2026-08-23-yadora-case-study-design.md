# Yadora 実績ページ刷新デザイン

## 目的

Kondax の Bocker 実績ページを Yadora のケーススタディへ置き換える。正式 URL は `/[locale]/work/yadora` とし、旧 `/[locale]/work/bocker` は恒久転送する。実績一覧、グローバルナビゲーション、フッターから Bocker 表記をなくし、Yadora への導線を統一する。

## 体験設計

「宿泊施設の運営画面」と「滞在体験」の両方を感じられる、静かで上質なエディトリアルデザインを採用する。Kondax の白基調を維持しながら、Yadora のフォレストグリーン、ミント、温かいサンド色をアクセントに使う。ファーストビューには個人情報を含まないダッシュボードの抽象モックを配置し、予約・稼働率・AI 提案が一目で伝わるようにする。

ページ構成は、価値提案、プロジェクト概要、OTA 依存という課題、3 ステップの仕組み、中核機能、運営基盤、成果指標、公式サイト CTA の順とする。コピーは Yadora 公式サイトの現行内容を基に、Kondax の開発実績として読める表現へ再編集する。日本語と英語を同じ情報構造で用意する。

## 実装方針

新規ページは Next.js App Router の Server Component として実装し、表示データは `next-intl` の翻訳辞書から取得する。視覚モックは HTML/CSS とアイコンで構成し、外部画像や実データには依存しない。旧 URL では `permanentRedirect` を使い、ロケールを保持する。メタデータ、canonical、Open Graph URL は新 URL に統一する。

## 検証

Node.js 22 で型チェックを含む本番ビルドを実行する。日本語・英語の新旧 URL、ナビゲーション、外部 CTA、モバイルとデスクトップ表示をブラウザで確認する。旧 URL が 308 転送されること、個人情報が表示されないこと、コンソールエラーがないことも確認する。
